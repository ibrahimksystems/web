# Ibrahim K. Systems — Open Template Customization

This project is the **actual Cruip Open React/Next.js template** customized for Ibrahim K. Systems / MSIAI.

The original Open architecture and visual system are retained; demo SaaS content has been replaced with MSIAI company, engineering, product, security, and contact content.

## Main changes

- MSIAI / Ibrahim K. Systems branding
- AI automation, AI agents, data engineering, cybersecurity, backend engineering, and custom software content
- WinCleaner Pro product section with supplied screenshots
- LinkedIn, GitHub, and Instagram links
- Company navigation: Products, Services, Security, Contact
- Gold/black brand accents while retaining the Open template's dark SaaS/developer aesthetic
- Responsive layout and AOS animations retained
- Static export enabled for Cloudflare Pages

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The static site is generated into:

```text
out/
```

## Cloudflare Pages

For a static Pages deployment, upload the contents of `out/` after a successful production build.

No production WinCleaner Pro executable is bundled in this website source. The public download should be connected only after the final EXE has been rebuilt against the actual production website hostname.

## Important

This package is a customized application built from the uploaded Open template. It is not a resale or redistribution of the unmodified template.
